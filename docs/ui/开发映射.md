# MikuToYou UI → 移动端开发映射（V2）

## 1. 目标

将 `docs/ui/ui-mockup.html` 与 `docs/ui/UI规范.md` 映射为当前 **React Native** 实现（纯客户端、无后端）。以仓库内真实路径为准。

> `ui-mockup.html` 仅作视觉参考；实现以 RN 组件与 `theme/tokens.ts` 为准。

## 3. 页面与组件映射

### 3.1 ChatScreen（聊天）

- **UI**：主聊天页。
- **组合**：`TopBar` → `Live2DPanel` → `MessageList` → `Composer`；未配置 API 时 `EmptyState`。
- **逻辑要点**：
  - 发送链路：`appendMessage(user)` **取返回值**作为 `sendChatMessage(settings, history)` 的上下文（禁止用闭包里的旧 `messages` 拼 history，避免 Tab 切换或父级重渲染后丢用户气泡）。
  - `AppContext.appendMessage` 内部必须用 **函数式** `setMessagesState(prev => [...prev, msg])`，禁止依赖 `[messages]` 闭包追加第二条消息。
  - `MessageList` 使用 `useIsFocused`，在 Tab 重新获得焦点时 `scrollToEnd`，避免回切后视口停在半截。

### 3.2 PersonalityScreen（人格）

- **UI**：网格卡片 +「不使用系统提示」+ 编辑 Modal；与 `UI规范` 中 Tab 与主色一致。
- **逻辑**：切换人格先 `clearChat()` 再 `updateSettings({ activePersonalityId })`；编辑写入 `personalityPresets`。

### 3.3 SettingsScreen（设置）

- **UI**：大模型字段、Live2D、保存 / 测试 / 清空聊天、关于等。
- **逻辑**：`testConnection` 来自 `src/modules/llm`；持久化经 `AppContext.replaceSettings` / `updateSettings` + `storage.saveSettings`。

### 3.4 RootTabs

- `@react-navigation/bottom-tabs`。
- **三个 Tab**：`聊天` → `ChatScreen`；`人格` → `PersonalityScreen`；`设置` → `SettingsScreen`。
- `NavigationContainer` 使用 `theme/navigationTheme.ts`；`tabBarBackground` + 透明 `tabBarStyle`、去阴影，避免叠层发灰。

## 4. Live2D（RN）

- `Live2DPanel`：`react-native-webview` + `live2dViewer.ts` 生成 html/baseUrl。
- RN ↔ WebView：`postMessage` / `onMessage`（加载成功、错误等）。

## 5. 类型（节选）

- `types/chat.ts`：`ChatMessage`、`ChatRole`。
- `types/settings.ts`：`AppSettings`（含 `personalityPresets`、`activePersonalityId`）、`normalizeAppSettings`。
- `modules/personality`：`PersonalityPreset` 等（可从 `types/settings` 再 export）。

## 6. 状态与存储

- **`AppContext`**：唯一数据源；`settings` / `messages`；`appendMessage` 返回 `Promise<ChatMessage[]>`；`clearChat` / `reload`。
- **`services/storage.ts`**：`loadSettings` 经 `normalizeAppSettings`；消息与设置分 key 存储。

## 7. 模块边界

| 模块 | 职责 | 禁止 |
|------|------|------|
| `modules/personality` | 预设列表、默认值、`ensurePersonalityFields` | 不发起网络请求 |
| `modules/llm` | `buildLlmMessageList`、`sendChatMessage`、`testConnection` | 不直接读写 AsyncStorage |
| `AppContext` | 组合设置与消息、触发持久化 | 不把业务规则写进 RN 视图层 |

## 8. 样式（Design Tokens）

- 与 `theme/tokens.ts` 一致：`colors.primary`、`colors.bg`、`radius`、`space` 等。
- 列表容器：`MessageList` 使用 `colors.panel` 与圆角，与 `UI规范` 面板色一致。

## 9. 推荐实现顺序（增量）

1. `RootTabs` + 三屏骨架 + `navigationTheme`。
2. `AppContext` + `storage` + 发送链路的 **函数式 append** 与 **返回值 history**。
3. `modules/llm` + `modules/personality` + `Settings` / `Personality` 表单。
4. `MessageList` 焦点滚动 + `Live2DPanel` 联调。

## 10. 验收清单

- 三 Tab 切换后，聊天列表仍完整显示 **用户 + 助手** 气泡顺序正确。
- 慢网络或切走 Tab 再返回后，不出现「只剩助手、用户气泡丢失」。
- 人格切换会清空聊天；设置保存与重启不丢。
- API 失败有 `error` 角色气泡；Live2D 失败不阻塞聊天。
