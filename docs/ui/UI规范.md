# MikuToYou UI规范（V2）

## 1. 目标与边界

- 本项目为纯客户端工具，不接入后端服务。
- MVP 聚焦三个底部 Tab：`聊天`、`人格`、`设置`。
- 聊天页同时承载消息流与 Live2D 展示区域。
- **人格页**：预置系统提示词（标题 + 内容网格），切换人格会先清空聊天再切换注入（见 `PersonalityScreen`）。
- 设置页负责大模型 API 与 Live2D 模型地址配置。
- **业务模块**：`src/modules/personality`（人格数据与归一化）、`src/modules/llm`（OpenAI 兼容请求与上下文拼装）；UI 层只通过 `AppContext` 与模块 API 交互，不在组件内散落 fetch/归一化逻辑。

## 2. 信息架构

- 全局：顶部栏 + 主内容区 + 底部 Tab。
- Tab 结构：
  - 聊天（默认）
  - 人格（预置提示词 / 系统消息注入）
  - 设置
- 底部 Tab 栏：背景与 `theme/tokens` 主背景一致，顶部分割线 `hairline`；当前项使用主色 `#39C5BB`，避免浅色 card 与页面叠层发灰。

## 3. 页面规范

### 3.1 聊天页（Chat Tab）

- 顶部栏：
  - 左：应用名 `MikuToYou`
  - 右：API 状态点（已配置/未配置）
- 主体：
  1. Live2D 展示卡片（建议占可视区域 30%~40%）
  2. 消息列表（滚动区域）
  3. 输入区（固定在底部导航上方）
- 空状态：
  - 当未配置 API 时，显示引导文案和“去设置”按钮。
- 异常状态：
  - 请求失败消息气泡；
  - Live2D 加载失败占位与“重试加载”。

### 3.2 人格页（Persona Tab）

- 布局：主区为 **双列网格**（卡片：标题 + 系统提示预览）；首行提供「不使用系统提示词」全宽入口。
- 当前选中人格：卡片描边 / 浅底使用主色半透明，与聊天侧用户气泡强调色同一色系。
- 编辑：Modal 内编辑标题与系统提示词；支持新增 / 删除预设。
- 与聊天联动：切换人格会清空本地聊天记录；大模型请求时的 system 由当前人格注入（不落库到消息列表）。

### 3.3 设置页（Settings Tab）

- 表单字段：
  - `API Base URL`（必填）
  - `API Key`（必填，支持显隐）
  - `Model`（可选，默认值可预置）
  - `Live2D 模型地址`（可选）
- 操作：
  - 保存设置（主按钮）
  - 测试连接（次按钮）
  - 清空聊天记录（危险按钮，需二次确认）

## 4. 组件规范

- `TopBar`：标题 + 状态点。
- `BottomTabs`：三个 tab，当前项主色高亮；与 `navigationTheme` 深色背景一致。
- `Live2DPanel`：Canvas 容器 + 错误占位层。
- `MessageBubble`：用户/助手两种样式。
- `Composer`：输入框 + 发送按钮。
- `SettingsForm`：字段校验与保存逻辑。
- `Toast`：短时反馈（保存成功/失败）。

## 5. 视觉规范（Design Tokens）

- 主色：`#39C5BB`
- 背景：`#0B1220`
- 面板：`rgba(255,255,255,0.08)`
- 文本主色：`#E6EDF7`
- 文本次色：`#94A3B8`
- 错误色：`#EF4444`
- 警告色：`#F59E0B`
- 圆角：`12px`、`16px`
- 阴影：低透明蓝青外发光
- 间距体系：8pt（8/12/16/24/32）

## 6. 交互状态机（MVP）

1. 首次进入聊天页，若未配置 API，展示空状态并引导到设置页。
2. 设置页保存成功后，聊天页可发起请求。
3. 发送消息时进入 loading，防止重复提交。
4. 接口失败时显示错误消息，不清空输入内容。
5. Live2D 模型加载失败时不阻塞聊天功能。
6. **聊天状态一致性**：追加消息须使用 `AppContext.appendMessage` 的函数式更新；发起 `sendChatMessage` 须使用「刚追加用户消息之后」返回的完整 `ChatMessage[]`，不得依赖 `await` 前后闭包中的旧 `messages`，以保证切换 Tab 或设置更新重渲染后仍保留用户气泡。
7. **消息列表**：从其他 Tab 回到聊天时，列表应滚动到底部，保证最新问答可见。

## 7. 合规与资源说明

- 开发测试阶段可使用免费 Live2D 测试模型进行联调。
- 初音未来相关模型通常受版权限制，使用前必须确认授权条款。
- 项目中建议新增 `assets-live2d/LICENSES.md` 记录资源来源与许可。
